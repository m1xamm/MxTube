## mxtube-project

MxTube is a private ad-free Android YouTube viewer for the user. Repo: https://github.com/m1xamm/MxTube.git.

Locked decisions: Russian UI. No Google login for now; watch history and subscriptions stay local, login later with an explicit warning. Monet dynamic colors on Android 12+ with a brand fallback. Must work on NothingOS, Pixel, Samsung and Xiaomi. In-app brand mark is the original cookie silhouette filled with `onSurface` and a transparent play-shaped cutout, no outline, so it works in light and dark themes. A matching black/white cutout splash icon is configured for Android 12+. The launcher icon still uses the original brand artwork plus a monochrome themed layer. No marketing copy, glows, outlines, decorative gradients, fake loading panels, oversized cards or decorative player menus. The navbar, player chrome, the video settings sheet and the landscape related cards use real Haze glass (ultraThin, no borders/hairlines); the user explicitly asked for the settings sheet and related cards to be glassy and rejected thin outlines.

Stack: Kotlin, Compose, Material3 1.5.0-beta02 Expressive, AGP 9.4.1, Gradle 9.6.0, compile/target SDK 37, min SDK 26, NewPipe Extractor v0.26.5, OkHttp 5.5.1, Media3 1.11.1, Coil 3.6.3. NewPipe Extractor is GPL-3.0.

Local emulator: AVD `mxtube`, Android 35 google_apis x86_64, 720x1600 at 320dpi, WHPX. The AVD is launched with -gpu host, but the current 0.7.0 session's EGL reports software emulation (SwiftShader), so emulator jank and animation speed are not authoritative for the phone. Start headless: emulator.exe -avd mxtube -no-snapshot -no-boot-anim -no-window -gpu host -no-audio. Use adb install and screencap. Toggle theme with `adb shell cmd uimode night yes|no` and restart the app.

**Design direction:** a compact floating pill, not a full-width rectangular bar. The selected tab expands into a pill containing icon+label; the other tabs are icon-only. The bar overlays content without a rectangular cutout; video/feed content shows through. The latest 2026-10-25 direction: all icons are uniform **24 dp** (no different inactive/selected sizes); inactive slots are 10 dp (44 dp touch item), bar end padding 6 dp and icon-to-icon spacing 24 dp; an icon-only end keeps 16 dp optical padding top/bottom and at the bar end; the selected pill keeps 8 dp on all sides. The selected tab is distinguished by the pill, label and color, not icon size. The bar uses real Haze glass like the player, not an alpha-only tint: the content Box is tagged with hazeSource(navHazeState), and the floating bar uses hazeBlur(HazeInput.Sources(navHazeState), HazeMaterials.ultraThin()) inside a CircleShape clip with no border/outline (the user rejected the hairline); the active pill remains opaque. Motion is deliberately slower and expressive: 360 ms spatial transitions with a mild cubic overshoot (0.26, 1.06, 0.18, 1.0), 240 ms colors/collapse, 180/120 ms label fades; no heavy springs. Keep the bar content-width, never fixed/widened. Press feedback is a clipped state layer, not a slot-wide ripple. Do not clip icons with offsets or inset background tricks.

## mxtube-emulator-youtube

The mxtube AVD's google_apis image ships a test-key-signed system YouTube in /product/app/YouTube that shows an "Update your app" wall (19.17.42). On 2026-11-12 the official Google-signed YouTube 21.45.82 (universal APK, APKPure, saved at MxTube-artifacts/apk/YouTube-21.45.82.apk) was installed by hiding the system app: `adb root`, `mkdir -p /data/local/tmp/empty`, `mount --bind /data/local/tmp/empty /product/app/YouTube`, `adb shell stop; adb shell start` (framework rescan), then `pm install -r /data/local/tmp/yt.apk`. adb remount/fastboot unlock do NOT work on this emulator (read-only dynamic partitions); the bind mount is the working trick.

**Why:** the user wants the real YouTube app (not web) on the emulator as the reference for channel/profile UX; the old stub cannot open channels.

**How to apply:** the bind mount does not survive an emulator reboot — after a reboot the system stub returns and shadows the official install. Redo: root → bind mount → stop/start → the official YouTube works again (no reinstall needed). Full tab set observed in 21.45.82 for a rich channel: Home, Videos, Shorts, Live, Playlists, Posts. See [[mxtube-project]].

## youtube-interaction-patterns

MxTube is YouTube with a better design, not a reinvention of YouTube. Preserve familiar controls and interaction patterns when restyling features.

**Why:** The user rejected repeated invented unsubscribe confirmation dialogs and clarified that the subscribed state should use a bell and a slide-up menu for notification options and unsubscribing, like the original YouTube app.

**How to apply:** Check the original interaction before redesigning an existing feature. For subscriptions, keep a bell/menu and direct unsubscribe action rather than a blocking confirmation dialog. Do not replace familiar workflows merely to follow a visual component guideline. Keep compact containers and verify the result visually before presenting it.

The user likes real Haze glass and explicitly wants it on notification/subscription sheets, other slide-up menus, and additional overlays where appropriate. Prefer genuine backdrop blur on floating controls over content; keep text and ordinary content cards readable, and do not fake the effect with transparency alone.

The user approved the current light/dark design after reviewing the paired screenshots on 2026-11-11. Subsequent work should focus on YouTube-like functionality and small behavioral defects, not redesigning approved colors, compact containers or glass menus. The subscriptions destination stays in MxTube's bottom navigation even if the original YouTube app moves it elsewhere.
